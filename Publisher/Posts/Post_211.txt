<b>بررسی Feature Gate در Code Review</b>
#AI_Code_Review(4/10)

در Code Review یک Feature تازه، نقطه‌ای را پیدا کن که رفتار جدید به مسیر فعلی برنامه وصل می‌شود. اگر Agent یک Component یا منطق جدید را جداگانه ساخته باشد، می‌توان آن بخش را در محدوده خودش بررسی کرد. نقطه اتصال توجه بیشتری می‌خواهد، چون همان‌جا مشخص می‌شود تغییر چه زمانی روی رفتار Production اثر می‌گذارد. طراحی Feature Gate از مرحله برنامه‌ریزی کمک می‌کند این نقطه در Diff قابل تشخیص باشد.

برای یک پیاده‌سازی ساده، Feature Gate می‌تواند یک Boolean Flag باشد که مسیر اجرای کد را تعیین می‌کند. هنگام Review، هر دو وضعیت Flag را در نظر بگیر و ببین با خاموش‌بودن آن، رفتار قبلی برنامه حفظ می‌شود یا نه. اگر بعد از فعال‌سازی مشکلی پیدا شد، باید بتوانی با خاموش‌کردن Gate به همان رفتار برگردی. این امکان روی میزان بررسی لازم برای ادغام تغییر اثر می‌گذارد.
