#AI_Legacy_Refactor(5/10)

قبل از اولین تغییر، قواعد Refactor را در فایل دستورهای پروژه ثبت کن تا هر Session از همان محدوده شروع کند. برای Claude Code می‌توان از `CLAUDE.md` و برای Codex از `AGENTS.md` استفاده کرد. مشخص کن حفظ رفتار فعلی شرط کار است و تغییر در امضای تابع‌های عمومی، HTTP Routeها، Database Schema و قالب Log خارج از محدوده است. اضافه کردن یا ارتقای Dependency را هم از کار جاری جدا نگه دار.

دستور اجرای تست و شرط توقف را صریح بنویس. برای نمونه، Agent پس از هر ویرایش در `src/` تست‌ها را اجرا کند و اگر یک تست دو بار شکست خورد، متوقف شود و نتیجه را گزارش کند. از Agent بخواه مواردی را که درباره حفظ رفتارشان مطمئن نیست با نشانه‌ای قابل جست‌وجو در کد مشخص کند و همان موارد را در گزارش تغییر بیاورد.
