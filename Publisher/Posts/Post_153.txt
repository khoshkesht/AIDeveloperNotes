#Context_Engineering(3/18)

وقتی با یک Agent کار می‌کنیم، Context فقط شامل سؤال فعلی کاربر نیست. system prompt، تعریف Toolها و نحوه استفاده از آن‌ها، chat history، خروجی Toolهای قبلی، اطلاعات بازیابی‌شده و خود درخواست کاربر همگی می‌توانند هم‌زمان وارد Context شوند. حتی درخواست کاربر ممکن است شامل حجم زیادی code یا error log باشد.

بخش قابل‌توجهی از رشد Context می‌تواند از old tool outputs ایجاد شود؛ مانند chunkهای بازیابی‌شده، جفت‌های tool call و tool result، fileها و searchهای قبلی. باقی ماندن همه این اطلاعات فقط هزینه را افزایش نمی‌دهد؛ Context بزرگ‌تر می‌تواند کیفیت را نیز کاهش دهد و با افزایش TTFT، زمان رسیدن اولین Token را بیشتر کند. بنابراین کوچک نگه داشتن Context هم مسئله کیفیت است، هم هزینه و هم latency.
