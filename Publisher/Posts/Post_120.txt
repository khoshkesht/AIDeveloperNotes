#AGENTS_MD (10/9)
<b>ارتباط AGENTS.md با MCP و Toolهای اختصاصی</b>
فایل AGENTS.md به Agent توضیح می‌دهد که پروژه چگونه باید توسعه پیدا کند، اما نحوه دسترسی Agent به منابع بیرونی را مشخص نمی‌کند. اینجاست که MCP و Toolهای اختصاصی وارد فرآیند می‌شوند. MCP امکان استفاده از سرویس‌ها، Repositoryها، Issue Trackerها، پایگاه‌های داده و سایر ابزارهای سازمان را در اختیار Agent قرار می‌دهد، در حالی که AGENTS.md مشخص می‌کند Agent در چه شرایطی و با چه رویکردی از این قابلیت‌ها استفاده کند.

برای مثال، ممکن است یک تیم از طریق MCP امکان دسترسی Agent به Jira، Git، مستندات داخلی و سرویس‌های Build را فراهم کرده باشد، اما در AGENTS.md مشخص شود که Agent مجاز به ایجاد Pull Request نیست، فقط باید Issueها را تحلیل کند یا قبل از هر تغییر از Tool مشخصی برای Validation استفاده کند. به همین دلیل، AGENTS.md و MCP مکمل یکدیگر هستند؛ یکی رفتار Agent را تعریف می‌کند و دیگری ابزارهای قابل استفاده را در اختیار او قرار می‌دهد.
