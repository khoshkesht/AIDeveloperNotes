#Codex (6/13)
<b>سازمان‌دهی پروژه‌ها و Chatها</b>
برای هر پروژه بهتر است فضای کاری مستقلی ایجاد شود تا تمام Chatها، فایل‌ها و تغییرات مرتبط در همان محدوده باقی بمانند. هر Project در عمل به یک پوشه روی سیستم متصل است و می‌تواند از ابتدا ساخته شود یا به یک Repository موجود متصل گردد. این ساختار پیدا کردن مکالمه‌های قبلی و ادامه توسعه را ساده‌تر می‌کند و از پراکندگی اطلاعات جلوگیری خواهد کرد.

پس از ایجاد Project، امکان انتخاب حالت Local، اتصال به نسخه Cloud یا ایجاد Worktree وجود دارد. همچنین Codex به‌صورت خودکار ارتباط پروژه با Git را برقرار می‌کند و Branch اولیه را ایجاد می‌کند. هنگام توسعه نیز می‌توان وضعیت فایل‌ها، تغییرات، Branchها، Terminal و Preview برنامه را از همان محیط مشاهده کرد و حتی پروژه را مستقیماً در IDE دلخواه باز کرد. نتیجه این ساختار، یک محیط یکپارچه برای توسعه، مدیریت کد و پیگیری تغییرات است که بدون خروج از Codex قابل استفاده خواهد بود.
