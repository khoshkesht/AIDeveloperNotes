<b>تحویل ساختاریافته میان Agentها</b>
#Task_Decomposition(10/14)

در workflowهای Multi-Agent، پایان یک Task معمولاً آغاز Task دیگری است. Handoff باید به‌شکل یک انتقال ساختاریافته انجام شود تا Agent دریافت‌کننده دقیقاً بداند چه کاری باقی مانده است. اطلاعاتی مانند Task Description، Context مرتبط، دلیل Handoff، Agent مبدأ، Expected Output و محدودیت زمانی می‌توانند بخشی از قرارداد انتقال باشند.

انتقال مستقیم میان Agentهای متخصص می‌تواند نیاز به بازگشت هر نتیجه به یک Hub مرکزی را کاهش دهد، اما استقلال بیشتر بدون Protocol مشخص خطر Context Loss را افزایش می‌دهد. Agent دریافت‌کننده نیز باید بتواند بر اساس capability خودش Task را قبول یا رد کند. اگر Task خارج از domain آن باشد، انتقال باید به Agent مناسب دیگری انجام شود، نه اینکه Agent کاری را انجام دهد که برای آن طراحی نشده است.
