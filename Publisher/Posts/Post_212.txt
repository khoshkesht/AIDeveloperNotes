<b>درخواست شواهد قابل‌بررسی در هر PR</b>
#AI_Code_Review(5/10)

برای بررسی کدی که Agent نوشته، از آن بخواه شواهد متناسب با نوع تغییر را داخل PR بگذارد. اگر منطق برنامه تغییر کرده، نام Unit Testها و Assertها را بخوان تا بفهمی چه رفتاری واقعاً بررسی شده است. اگر نتیجه هنگام اجرا مشخص می‌شود، Runtime Log را ببین. برای تغییر UI، Screenshot یا ضبط صفحه می‌تواند نتیجه را نشان دهد. مثلاً در PR مربوط به ذخیره کارت، Reviewer می‌تواند وضعیت رابط پس از ذخیره را در شواهد تصویری ببیند.

قالب PR را طوری تنظیم کن که توضیح تغییر، Test Plan و شواهد Validation به‌راحتی پیدا شوند. می‌توانی از Agent بخواهی میزان اطمینانش به بخش‌های مختلف کد و Feature Gate را هم مشخص کند. درخواست شواهد و قواعد نوشتن تست‌های مفید را در یک Skill ثبت کن تا Agent آن‌ها را هنگام آماده‌کردن هر PR اعمال کند.
