<b>آماده‌کردن Code Review از مرحله Spec</b>
#AI_Code_Review(2/10)

پیش از تولید کد، مشخص کن یک Feature کامل چه رفتاری دارد و با چه معیارهایی می‌توان آن را بررسی کرد. از Agent برای آماده‌کردن Spec و مشخص‌کردن معیارهای Validation کمک بگیر. وقتی این معیارها از ابتدا روشن باشند، Agent هنگام پیاده‌سازی می‌تواند نتیجه کارش را بررسی کند، ایرادهایی را که پیدا می‌کند اصلاح کند و برای Review شواهدی از اجرای همان بررسی‌ها آماده کند.

در زمان Code Review، معیارهای اولیه را کنار شواهد PR بگذار و بررسی کن پیاده‌سازی تا چه حد رفتار مورد انتظار را پوشش داده است. برنامه Launch هم روی تصمیم Reviewer اثر دارد. اگر Feature پشت Gate باشد و بتوان آن را در یک Experiment بررسی کرد، بخشی از اعتبارسنجی پس از Merge و در Production انجام می‌شود. به این ترتیب، تصمیم درباره عمق Review از مرحله Spec شروع می‌شود و تا Launch ادامه پیدا می‌کند.
